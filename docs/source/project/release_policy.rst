==============
Release Policy
==============

MC/DC follows `Semantic Versioning <https://semver.org/>`_ and maintains its
release history in
`CHANGELOG.md <https://github.com/mcdc-project/mcdc/blob/dev/CHANGELOG.md>`_.

Minor Releases
--------------

MC/DC plans a minor release each month. These releases collect compatible
features, improvements, and fixes that have passed the project's required
review and validation.

The monthly schedule is a target rather than a reason to release unverified
work. A release may be delayed when additional testing, documentation, or
integration work is needed.

Patch Releases
--------------

Bug fixes are not held until the next monthly minor release. Once a fix has
passed review and the relevant validation and release checks, MC/DC publishes
a patch release as soon as practical.

Published versions and release notes are available from the
`MC/DC releases page <https://github.com/mcdc-project/mcdc/releases>`_.
